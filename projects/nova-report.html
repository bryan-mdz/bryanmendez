EL PROYECTO

Una visión ejecutiva del desempeño comercial.

El proyecto fue diseñado para centralizar en una sola experiencia los principales indicadores relacionados con el desempeño comercial.

El dashboard permite analizar resultados desde diferentes perspectivas, combinando indicadores ejecutivos, evolución temporal, presupuesto, rentabilidad y segmentación comercial.

Para enriquecer la experiencia visual se combinaron visualizaciones tradicionales de Power BI con componentes personalizados desarrollados mediante HTML Content.

OBJETIVO

Convertir información comercial en una herramienta clara para la toma de decisiones.

El diseño prioriza jerarquía visual, navegación sencilla y acceso rápido a los indicadores más relevantes.
